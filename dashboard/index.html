資料說明

沒有選課人數。人限不是剩餘名額；空白表示未提供，0 的意義尚未確認。

資料時間為 Git commit 時間，不是固定每小時或即時更新。第一筆作為比較基準；課程從紀錄移除不代表停開。

開課單位依科號代碼分組。通識採用原資料的類別；多位教師或多間教室合列時，不另行拆分。

同課同節次只計一次。異常時段不列入統計，原文保留在課程詳情；節次代碼不換算鐘點。

選課限制、擋修及加簽規則以校方公告為準。
